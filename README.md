# 秒记 · Miaoji

桌面常驻的英文生词速记本：复制一个词或句子 → 点开橙色像素小机器人 → 回车 → AI 给出释义、例句、词源脉络，并自动写进 Obsidian。界面是深色终端风：等宽字、提示符、橙色高亮。

## 快速开始

1. 双击 `release\秒记-Setup-1.3.4.exe` 安装。安装器默认装到 `D:\秒记`（目录页可以改），当前用户安装，不需要管理员权限。
2. 第一次运行后，点桌面上的像素小机器人（或按 `Ctrl + Alt + M`），切到「设置」。
3. 填入 **DeepSeek API Key**（在 https://platform.deepseek.com 申请），点「保存」→「测试连接」。
4. 确认「Obsidian 生词本」路径，默认是：
   `D:\Obsdian\知识库\秒记\生词本.md`
   文件不存在时会在第一次查词时自动创建。

## 日常用法

- **常驻**：屏幕边上一个可以拖动的像素小机器人，位置会记住。气泡贴在机器人头顶：首次显示「查词」，之后显示「今日 N」。
- **查词**：复制英文 → 点机器人展开，剪贴板内容会自动带入输入框并选中 → 回车。
  也可以直接在输入框里手打；`Shift + Enter` 换行。
- **收起**：右上角 ✕ 或 `Esc`。
- **低频操作**：查词、热词、设置收在右上角图标里；查新词用词头上的 ＋，打开生词本和收起也在右上角。
- **快捷键**：`Ctrl + Alt + M` 全局唤出/收起（被输入法或其他软件占用时可能失效）。输入框内 `Enter` 解析、`Shift + Enter` 换行；完整键位表在设置页的「快捷键」分组，不占用查词界面。
- **三块内容**：结果页顶部横排分区切换，词头始终留在顶部，内容占满整张卡片：
  - `01 释义`：中文释义、英文定义、例句、近义/搭配、记忆法。
  - `02 脉络`：词源、最早用例、从源头到现在的演变故事、时间线、关联场景、辨析和相关词。技术词会重点讲它怎么进入技术语境。
  - `03 追问`：对当前词继续提问，回答会自动接在下面，并写进 Obsidian。
- **追问**：切到 `03 追问`，输入问题回车。可以连续追问，最多保留最近 40 条消息。
- **朗读**：词头旁边的喇叭按钮。
- **热词**：同一个词查满 3 次（设置里可改阈值）就会进「热词」页和笔记顶部的热词榜。
  - 点热词条目可以看详情：`重新解析`（次数 +1）、`标记掌握`、`删除`。
  - 「已掌握」的词不再算热词，但记录和笔记里的词条会保留。
- **托盘**：右键托盘图标可以打开、收起、打开生词本、设置、开机自启、退出。
- **数据位置**：设置页会显示数据/程序目录，点「打开」可以直接在资源管理器里打开数据目录。

## Obsidian 笔记怎么组织

只有一个文件，结构固定：

```markdown
# 📒 秒记生词本

<!-- sm-hot-start -->
## 🔥 热词榜
| 词条 | 释义 | 次数 | 最近查询 |
<!-- sm-hot-end -->

## 全部词条

<!-- sm:entry:ubiquitous -->
## ubiquitous
...释义、例句...
> [!note] 词源与脉络
> 词源、最早、演变故事、时间线、关联场景、辨析、相关词

> [!question]- 追问记录（N 轮）
> 你：...
> 小记：...
<!-- /sm:entry:ubiquitous -->
```

- 同一个词再次查询只会更新次数和内容，不会重复添加。
- 每个词条由 `<!-- sm:entry:... -->` 标记块包住，工具只会改块内的内容。
  想补自己的笔记，写在标记块外面即可，不会被覆盖。
- 追问记录是折叠的 callout，不会把整篇笔记撑得太长。
- 「按本地记录重新生成整篇笔记」是一次性重建，会丢掉你手动加在文件里的内容，慎用。

## 数据、隐私与 C 盘

- 程序默认安装到 `D:\秒记`；配置、词条和 Electron 会话数据默认放在 `D:\秒记数据`。
- D 盘不可用时才回退到系统默认目录（C 盘用户目录）。
- 从旧版本升级时，会自动把 `%APPDATA%\miaoji` 里的配置、词条和 `Local State` 复制到 `D:\秒记数据`。
  如果旧 Key 因为系统凭据变化无法解密，在设置里重新填一次即可。
- API Key 用 Windows 凭据加密后保存在 `D:\秒记数据\config.json`（密文，不是明文）。
- 词条记录保存在 `D:\秒记数据\entries.json`。
- 只有查词/追问时把「你输入的词、句子或问题」发给 DeepSeek；没有别的联网行为。
- 安装包没有代码签名，Windows SmartScreen 可能提示「已保护你的电脑」，选择「更多信息 → 仍要运行」即可。

## 开发

```bash
npm install
npm start          # 开发运行
npm run icons      # 重新生成像素图标（需要 Python + Pillow）
npm run dist       # 打包 Windows 安装包到 release\
```

开发/调试用的环境变量（不会影响正常使用）：

- `MIAOJI_DATA_DIR`：把配置和词条记录指向临时目录
- `MIAOJI_VAULT_FILE`：把生词本指向临时文件，避免污染真实库
- `MIAOJI_MOCK=1`：不请求 AI，返回固定的测试词条
- `MIAOJI_EXPAND=1`：启动后自动展开
- `MIAOJI_NAV=hot|settings`：启动后自动切页
- `MIAOJI_TEST_QUERY=...`：启动后自动查一个词
- `MIAOJI_TEST_REPEAT=N`：把上面的自动查询重复 N+1 次
- `MIAOJI_TEST_FOLLOWUP=...`：查词后自动追问一句
- `MIAOJI_TEST_ZONE=0|1|2`：查词后自动切到释义/脉络/追问分区

## 界面

- 暖米白纸面终端风：纸面 `#F7F3EA`，卡片 `#FFFCF5`，深墨字 `#22201D`，橙 `#B4522F`。不用黑底，长时间读释义更舒服。
- 界面文字统一使用系统等宽字体 **Consolas**（缺少时回退 Cascadia Mono / Microsoft YaHei UI）。
- 词头前是 `›` 提示符，分区编号写作 `[01] [02] [03]`，小标题用 `//` 开头，标签用 `[标签]` 包住。
- 标题栏里的 42px 像素小机器人直接落在纸面上，不加外框，机器人头顶略高于标题；「秒记」标题收到 15px，用宋体感字面 + 橙色渐变，像打在纸上的打字机字，状态行 10px。折叠态也是同一只橙色像素机器人：宽扁身体、两只黑方眼、横向手臂、四条短腿。应用图标和托盘图标使用同一造型。

## 机器人小引擎

参考 Grok Bot 的思路，机器人不是循环一段固定动画，而是一个小型状态机：

- **空闲**：从「眨眼、单眼眨、看左/右/上/下、歪头、挤压、跳一下」里随机抽片段，1.4–3.4 秒一段，尽量避免连续重复；眨眼有概率连眨两下。
- **空态大机器人**：结果区里 96px 的那只也走同一套状态机，不再只有上下浮动；鼠标靠近时会追着光标看，身体跟着轻微歪头。
- **思考**：解析或追问时眼睛上移；折叠态停留超过 1.6 秒，形态变换成三个橙色方块 `...`，结果回来再变回机器人。
- **成功 / 出错**：成功短暂笑眼 + 轻弹，出错时一只眼睛压低并轻抖。
- **睡觉**：折叠且 60 秒无操作后闭眼慢呼吸；鼠标移入、点击或拖拽即醒。
- **小尺寸**：42px 标题栏头像使用单独的 64px `compact` 帧和 2.6–5.4 秒的片段池，看左右时整只头像会轻微歪头。
- 尊重系统「减少动态效果」设置；窗口不可见时暂停空闲片段。

## 字体

界面使用系统等宽字体 Consolas，不额外打包字体文件。
`renderer/fonts/` 中保留早期版本使用的 **Cubic 11** 像素字体（SIL Open Font License 1.1），授权文本见 `renderer/fonts/OFL.txt`；当前终端皮肤不再引用它。

```
  preload.js    contextBridge 安全桥

  index.html / styles.css / terminal.css / app.js
  assets/       机器人表情帧

tools/          像素图标生成脚本
build/          NSIS 安装器脚本（默认 D 盘）
```

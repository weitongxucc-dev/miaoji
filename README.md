# 秒记 · Miaoji

桌面常驻的英文生词速记本：复制一个词或句子 → 点开橙色像素小机器人 → 回车 → AI 给出释义、例句、词源脉络，并自动写进 Obsidian。界面是暖纸色终端风：等宽字、提示符、朱砂橙高亮。

v1.4 起多了两件大事：**学习方向**（AI 按你设定的领域解释词条，同一个词在不同领域含义不同）和**回顾**（为复习而记录：先想再翻的间隔复习、词头术语卡、诚实的差距统计）。

v1.5 补上了「记录」的另一半：**网页链接剪藏**（摘要 + 术语标注 + 原文全文）、**闪念记录**、**中文反查**，以及选中文字后一键送进来的 `Ctrl + Alt + S`。

v1.6 把「回报」和 Agent 能力接上：**洞察统计**（近 7 天曲条图、方向分布、连续天数、诚实的薄弱统计）、**AI 考官**（出题、判分、解析，答题结果直接安排复习）、**周报**（写入 Obsidian）、**文章术语流水线**（一键把剪藏的术语全部收进复习）、**助手**（DeepSeek 工具调用，让它自己查、收、改方向、看统计、写周报），以及默认关闭、只在本机运行的**剪贴板提示**和**本地学习建议**。

v1.7 把「链接」做扎实：**视频链接剪藏**（YouTube / B站 / 抖音 / TikTok / Vimeo / 西瓜 / 快手 / X：本地取标题、作者、时长、简介和字幕，含自动字幕），以及**文章提取升级**（本机 Chromium 渲染 + Mozilla Readability，JS 动态渲染的页面也能拿正文）。视频和文章提取全部在本机完成，不经过第三方服务。

v1.8 补上长期使用需要的几件事：**检查更新**（启动时每天最多查一次版本，设置页可手动检查）、**自动周报**（默认关闭，每满 7 天写入 Obsidian）、**洞察区间切换**（7 天 / 30 天 / 本月），以及可选的**受限视频登录状态**（默认关闭，抓取失败时借用本机浏览器登录状态重试）。

v1.9 修的是「用久了才会遇到」的问题：**积压可见、可一次清完**（到期数超过日额度时给出「清积压」按钮），**毕业长尾确认**（毕业后 60 / 120 / 240 天各回来一次，避免「毕业即遗忘」），以及**受限文章站点**（知乎 403 给出可执行提示；公众号优先静态抓取；需要登录的站点可在设置里填 Cookie，只对指定域名生效、本机加密保存）。

## 快速开始

1. 双击 `release\秒记-Setup-1.9.0.exe` 安装，或在 [Releases](https://github.com/weitongxucc-dev/miaoji/releases/latest) 下载 `miaoji-Setup-1.9.0.exe`。安装器默认装到 `D:\秒记`（目录页可以改），当前用户安装，不需要管理员权限。没有安装 Obsidian 时，安装器会提示一次，可以直接跳过。
2. 第一次运行后，点桌面上的像素小机器人（或按 `Ctrl + Alt + M`），会弹出「笔记写到哪？」：
   - 检测到 Obsidian：选一个库，笔记自动写到「库\秒记\生词本.md」，不用手动找路径。
   - 没检测到：可以点「下载 Obsidian」，或者选「先不用 Obsidian」先把词条存在本机，之后在设置里随时开启。
3. 填入 **DeepSeek API Key**（在 https://platform.deepseek.com 申请），点「保存」→「测试连接」。
4. 之后可以在「设置 → 笔记」里重新检测 Obsidian、切换库、换生词本文件，或关闭笔记写入。

## 日常用法

- **常驻**：屏幕边上一个可以拖动的像素小机器人，位置会记住。气泡贴在机器人头顶：首次显示「查词」，之后显示「今日 N」；有到期待复习的词时优先显示「回顾 N」，机器人成为复习信使。
- **查词**：复制英文 → 点机器人展开，剪贴板内容会自动带入输入框并选中 → 回车。
  也可以直接在输入框里手打；`Shift + Enter` 换行。中文输入（术语、概念）也可以：AI 会给一张「术语卡」（定义、领域例句、近义、搭配、为什么重要、常见误解），适合学 AI、编程、供应链等陌生领域的黑话。
- **三种捕获方式**：输入框下方有三个切换按钮，默认「查词」。
  - `查词`：单词、短语、句子；**粘贴一个 http(s) 网页链接**时自动变成剪藏——抓正文、出摘要、标术语，原文完整保留在「02 原文」分区和 Obsidian 的折叠引用里。支持 JS 动态渲染的页面（本机 Chromium 渲染 + Readability，服务器直出页面有零依赖兜底）。遇到反爬验证页、404、只给试读的付费墙会明确报错，不会把假内容当文章存进来。
  - **视频链接**：粘贴 YouTube / B站 / 抖音 / TikTok / Vimeo / 西瓜视频 / 快手 / X 的视频链接，自动识别为视频剪藏：本地取标题、作者、时长、简介和字幕（官方字幕优先，其次自动字幕），AI 生成摘要与术语，字幕或简介全文写进「02 原文」与 Obsidian。**没有字幕的视频**诚实地只存简介（连简介都没有就只存标题），不编造文案。视频引擎随安装包分发，全部在本机运行。
  - `中→英`：输入中文，给出最贴切的英文表达和几个备选，说明语体与场合差别。适合「想表达但想不起词」。
  - `闪念`：随手记一段想法或摘录，AI 只做轻整理（标题、要点、术语），**不改写你的话**，原文完整保留。
  - 剪藏和闪念里标出的术语，点一下就能单独收进复习队列。
- **划词快捷键**：在外面选中一段文字，按 `Ctrl + Alt + S`，秒记自动展开并开始解析（优先读系统选区，读不到时退回复制剪贴板，并还原你原来的剪贴板内容）。
- **学习方向**：设置里自己定方向，数量不限（编程 / 供应链 / 网络安全 / 产品…，也可以写成你所在行业的具体岗位方向）。设定后，AI 解释词条会贴合方向语境（`port` 在编程和供应链里是两回事），并自动建议新词条的归属；词头上可以随时手动改。笔记里每个词条也会标注它的方向。
- **回顾**：导航栏的循环图标。每天最多复习设定数量（默认 5 个，宁少勿多）：
  - 到期的词先展示词面，**先想它的意思，再翻面**（`空格` 翻面）；
  - 翻面后三个自评按钮：`1 没想起`（明天再来）、`2 模糊`（间隔随阶段增长，连续两次模糊也算一次进步）、`3 想起来了`（进入下一阶段：3 → 7 → 14 → 30 天，毕业）；
  - 到期数超过今天的额度时，页面会明说「另有 N 个已到期」，并给一个「清积压」按钮一次清完；
  - 毕业后不会从此消失：60 / 120 / 240 天各回来确认一次（卡片上标「毕业确认」），答对继续往后排，答错回到复习队列重走；
  - 页头是诚实的差距统计：`已收 N · 复习过 M · 稳固 K`——收藏不等于掌握；
  - 复习结果会同步回 Obsidian（`✅ 已掌握` / `🏅 复习毕业`）。
- **洞察**：导航栏的折线图标。**7 天 / 30 天 / 本月**三种区间可切，双色柱图（悬停看数值，也可展开「看数字」表格）、方向分布、连续学习天数，以及一排不粉饰的数字：收录 / 复习过 / 稳固 / 到期。这里还有「还不稳的词」——所选区间内「没想起」次数最多的记录。
- **AI 考官**：回顾页右上角的「AI 考官」。按到期词生成中文单选题，`1`–`4` 选答案，答完立即判分并给一句解析；答对进入下一复习阶段，答错明天回来。中途可以「退出考官」，结果照常计入统计。
- **周报**：洞察页底部「生成本周周报」。根据过去 7 天的本地数据生成一页摘要（做了什么、哪些不稳、下一步），写入 Obsidian 同目录的「秒记周报.md」；同一周重复生成会更新同一块，不覆盖旧周报。没开笔记写入时只在页面显示。设置 → 笔记里可以打开「每满 7 天自动生成周报」（默认关闭），开启且已写 Obsidian 时自动生成，没有学习记录时顺延。
- **文章术语流水线**：剪藏详情里点「把这 N 个术语全部收进复习」，逐条查词、建卡、排复习并写笔记，按钮会显示当前进度。
- **助手**：导航栏的星形图标。用 DeepSeek 工具调用直接操作本机词条库：搜索、查词收录、改方向、看到期、提交复习、看统计、批量收文章术语、生成周报。适合一句话完成多步任务，比如「查一下 idempotent 并放进编程方向」。它不会删笔记、不会改 API Key。
- **剪贴板提示（默认关闭）**：设置 →「监听与建议」开启后，在其他软件里复制一个词或短语，机器人头顶会冒出「收 xxx」，点一下才展开并解析。只在本机做规则匹配，不联网、不记录来源；可随时「暂停监听」。不用时保持关闭即可。
- **本地学习建议（默认关闭）**：开启后，洞察页会按你自己的复习数据给 1–3 条规则建议（今天先复习哪些、哪个方向词太少、哪个词总想不起来），回顾/考官结束时也会提示明天先过哪几个。纯本地计算，没有广告、没有行为画像。
- **检查更新**：启动时每天最多向 GitHub 查一次公开版本号（不发送任何本机数据），有新版本会在右下角提示；设置 →「版本」里可以手动检查，并一键打开下载页。不做静默自动安装：安装包未签名，部分网络也会拦截下载，交给你决定更稳妥。
- **受限视频登录状态（默认关闭）**：设置 →「视频平台」里选一个你登录过该网站的浏览器（Edge / Chrome / Firefox / Brave）。抖音、TikTok、X 等需要登录的视频，正常抓取失败时会读取该浏览器登录状态重试一次；cookie 只在本机交给视频引擎读取，不保存副本、不上传。新版 Edge/Chrome 的 cookie 加密可能导致读取失败，Firefox 兼容最好。
- **受限文章站点（可选）**：有些网站（如知乎）不登录就返回 403。设置 →「受限文章」里填站点域名和浏览器里登录后的 Cookie 整段，之后抓取这个域名时会自动带上，其他站点不会收到。Cookie 用 Windows 凭据加密保存在本机、保存后不回显；知乎 403 时也会直接告诉你去这里填。
- **公众号链接**：`mp.weixin.qq.com` 的文章直接走静态抓取（公众号页面是服务器直出的，隐藏窗口反而会撞上「环境异常」验证页），通常能正常拿到正文。
- **收起**：单击页眉上的机器人和「秒记」、右上角 ✕，或按 `Esc`。单击品牌区立即收起；按住不放约半秒，机器人会原地乱扭一通，松开后自动恢复（长按不会收起）。
- **逗它**：折叠状态下按住小机器人约半秒，眼睛会左右晃、眯眼、坏笑、惊讶地快速轮换，头顶气泡还会冒一句俏皮话；松开恢复。拖动机器人时气泡会暂时隐藏，松手后再出现。
- **低频操作**：查词、热词、回顾、洞察、助手、设置收在右上角图标里；查新词用词头上的 ＋，收起在右上角。「打开生词本」在设置 → 笔记里，托盘菜单也可以直接打开。
- **快捷键**：`Ctrl + Alt + M` 全局唤出/收起，`Ctrl + Alt + S` 划词送进秒记（被输入法或其他软件占用时可能失效）。输入框内 `Enter` 解析、`Shift + Enter` 换行；回顾页 `空格` 翻面、`1/2/3` 自评；考官页 `1`–`4` 选答案、翻面后 `Enter` 下一题。完整键位表在设置页的「快捷键」分组，不占用查词界面。
- **三块内容**：结果页顶部横排分区切换，词头始终留在顶部，内容占满整张卡片：
  - `01 释义`：中文释义、英文定义、例句、近义/搭配、记忆法。反查结果是「释义」。
  - `02 脉络`：词源、最早用例、从源头到现在的演变故事、时间线、关联场景、辨析和相关词。技术词会重点讲它怎么进入技术语境。反查是「辨析」（备选表达和差别），剪藏/闪念是「原文」全文。
  - `03 追问`：对当前词继续提问，回答会自动接在下面，并写进 Obsidian。剪藏和闪念同样可以追问。
- **追问**：切到 `03 追问`，输入问题回车。可以连续追问，最多保留最近 40 条消息。
- **朗读**：词头旁边的喇叭按钮。
- **热词**：同一个词查满 3 次（设置里可改阈值）就会进「热词」页和笔记顶部的热词榜。
  - 点热词条目可以看详情：`重新解析`（次数 +1）、`标记掌握`、`删除`。
  - 「已掌握」的词不再算热词，但记录和笔记里的词条会保留。
- **托盘**：右键托盘图标可以打开、收起、打开生词本、设置、开机自启、退出。折叠成小机器人后，右键它也有同样的菜单（展开、生词本、设置、开机自启、退出）。
- **数据位置**：设置页会显示数据/程序目录，点「打开」可以直接在资源管理器里打开数据目录。

## Obsidian 笔记怎么组织

只有一个文件，结构固定：

```markdown
# 📒 秒记生词本

<!-- sm-hot-start -->
## 🔥 热词榜
| 词条 | 释义 | 次数 | 最近查询 |
<!-- sm-hot-end -->

## 全部词条

<!-- sm:entry:ubiquitous -->
## ubiquitous
...释义、例句...
> [!note] 词源与脉络
> 词源、最早、演变故事、时间线、关联场景、辨析、相关词

> [!question]- 追问记录（N 轮）
> 你：...
> 小记：...
<!-- /sm:entry:ubiquitous -->
```

- 同一个词再次查询只会更新次数和内容，不会重复添加。
- 每个词条由 `<!-- sm:entry:... -->` 标记块包住，工具只会改块内的内容。
  想补自己的笔记，写在标记块外面即可，不会被覆盖。
- 追问记录是折叠的 callout，不会把整篇笔记撑得太长。
- 「按本地记录重新生成整篇笔记」是一次性重建，会丢掉你手动加在文件里的内容，慎用。
- 周报写到同一目录的「秒记周报.md」，每周一个标记块，重新生成只更新当周，不动旧周报。

## 数据、隐私与 C 盘

- 程序默认安装到 `D:\秒记`；配置、词条和 Electron 会话数据默认放在 `D:\秒记数据`。
- D 盘不可用时才回退到系统默认目录（C 盘用户目录）。
- 从旧版本升级时，会自动把 `%APPDATA%\miaoji` 里的配置、词条和 `Local State` 复制到 `D:\秒记数据`。
  如果旧 Key 因为系统凭据变化无法解密，在设置里重新填一次即可。
- API Key 用 Windows 凭据加密后保存在 `D:\秒记数据\config.json`（密文，不是明文）。
- 词条记录保存在 `D:\秒记数据\entries.json`。
- Obsidian 检测只查三处：`obsidian://` 协议注册表、`%APPDATA%\obsidian\obsidian.json` 里的库列表、几个标准安装路径。不扫描磁盘。
- 没有 Obsidian 或关掉笔记写入时，查词和追问照常工作，只保存在本地；不会因为写不了笔记而失败。
- 只有你主动使用 AI 功能时才联网，发给 DeepSeek 的内容是：查词/追问/剪藏/反查时你给的内容，考官/周报时的本地学习数据摘要，使用助手时的指令和工具需要的词条摘要（词、释义、方向、复习状态）。不使用这些功能就不会发送。
- 剪贴板监听默认关闭；开启后也只在本机读取剪贴板做规则匹配，只有你点机器人头顶的「收 xxx」才会联网解析。本地学习建议完全在本机计算。
- 网页正文和视频信息全部在本机提取：网页用内置 Chromium 加载 + 本地 Readability 算法，视频用随包分发的 yt-dlp 直连平台取字幕，不经过任何第三方转换/代理服务，也不上传页面内容。只有提取出的文字会和你的 API Key 一起发给 DeepSeek 做摘要。隐藏的提取窗口使用独立内存会话，不保存 cookie，也不在后台常驻。
- 版本检查只请求 GitHub 的公开版本信息，不发送任何本机数据。自动周报和受限视频登录状态都默认关闭，开启后也只在本机读取学习记录或浏览器登录状态。
- 受限文章站点的 Cookie 由你手动粘贴，用 Windows 凭据加密后保存在 `config.json`（密文），保存后不会回显；只有抓取你填写的那个域名时才会作为请求头发送，其他站点一律不带。
- 安装包没有代码签名，Windows SmartScreen 可能提示「已保护你的电脑」，选择「更多信息 → 仍要运行」即可。

## 开发

功能规划与状态见 [ROADMAP.md](ROADMAP.md)。

```bash
npm install
npm start          # 开发运行
npm run icons      # 重新生成像素图标（需要 Python + Pillow）
npm run dist       # 打包 Windows 安装包到 release\
```

开发/调试用的环境变量（不会影响正常使用）：

- `MIAOJI_DATA_DIR`：把配置和词条记录指向临时目录
- `MIAOJI_VAULT_FILE`：把生词本指向临时文件，避免污染真实库
- `MIAOJI_MOCK=1`：不请求 AI，返回固定的测试词条
- `MIAOJI_OBSIDIAN_MOCK=none`：假装没有安装 Obsidian，用来测试首次引导和降级流程
- `MIAOJI_ALLOW_LOCAL_FETCH=1`：仅开发用，允许剪藏抓取 127.0.0.1 等内网地址，方便本地网页测试；正常运行时 SSRF 防护默认开启
- `MIAOJI_EXPAND=1`：启动后自动展开
- `MIAOJI_NAV=hot|settings`：启动后自动切页
- `MIAOJI_TEST_QUERY=...`：启动后自动查一个词
- `MIAOJI_TEST_REPEAT=N`：把上面的自动查询重复 N+1 次
- `MIAOJI_TEST_FOLLOWUP=...`：查词后自动追问一句
- `MIAOJI_TEST_ZONE=0|1|2`：查词后自动切到释义/脉络/追问分区

## 界面

- 暖米白纸面终端风：纸面 `#F7F3EA`，卡片 `#FFFCF5`，深墨字 `#22201D`，橙 `#B4522F`。不用黑底，长时间读释义更舒服。
- 界面文字统一使用系统等宽字体 **Consolas**（缺少时回退 Cascadia Mono / Microsoft YaHei UI）。
- 词头前是 `›` 提示符，分区编号写作 `[01] [02] [03]`，小标题用 `//` 开头，标签用 `[标签]` 包住。
- 标题栏里的 42px 像素小机器人直接落在纸面上，不加外框，机器人头顶略高于标题；「秒记」标题收到 15px，用宋体感字面 + 橙色渐变，像打在纸上的打字机字，状态行 10px。折叠态也是同一只橙色像素机器人：宽扁身体、两只黑方眼、一小条嘴巴、横向手臂、四条短腿。应用图标和托盘图标使用同一造型。表情除眨眼、看四向、笑、思考、困惑、睡觉外，还有眯眯眼、惊讶、坏笑。
- 正文做了轻量排版：多义项按 `[01] [02]` 编号分行；例句里的词条会加淡橙色底标记；追问回答按换行分段，支持 `- ` / `1. ` 列表和 `**加粗**` 强调；AI 返回的 HTML 一律先转义再渲染，不会执行标记。

## 机器人小引擎

参考 Grok Bot 的思路，机器人不是循环一段固定动画，而是一个小型状态机：

- **空闲**：从「眨眼、单眼眨、看左/右/上/下、歪头、挤压、跳一下」里随机抽片段，1.4–3.4 秒一段，尽量避免连续重复；眨眼有概率连眨两下。
- **空态大机器人**：结果区里 96px 的那只也走同一套状态机，不再只有上下浮动；鼠标靠近时会追着光标看，身体跟着轻微歪头。
- **思考**：解析或追问时眼睛上移；折叠态停留超过 1.6 秒，形态变换成三个橙色方块 `...`，结果回来再变回机器人。
- **成功 / 出错**：成功短暂笑眼 + 轻弹，出错时一只眼睛压低并轻抖。
- **睡觉**：折叠且 60 秒无操作后闭眼慢呼吸；鼠标移入、点击或拖拽即醒。
- **小尺寸**：42px 标题栏头像使用单独的 64px `compact` 帧和 2.6–5.4 秒的片段池，看左右时整只头像会轻微歪头。
- **长按发疯**：在页眉品牌区按住约半秒，头像进入疯狂扭动模式，快速轮换眨眼、单眼眨和四个方向，松开再持续半秒收尾；长按只表演，不收起面板。
- 尊重系统「减少动态效果」设置；窗口不可见时暂停空闲片段（长按发疯也会直接跳过）。

## 字体

界面使用系统等宽字体 Consolas，不额外打包字体文件。
`renderer/fonts/` 中保留早期版本使用的 **Cubic 11** 像素字体（SIL Open Font License 1.1），授权文本见 `renderer/fonts/OFL.txt`；当前终端皮肤不再引用它。

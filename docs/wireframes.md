# 秒记页面结构与线框

状态：v0.5（2026-11-18）。第三批（3+3 框架与闪念页）与审计修复已按本文件落地；仍是结构稿，不是最终视觉稿。先确认页面清单、每页 P0 和线框，再进入 token 与视觉页面。

产品定位与边界见 `docs/brief.md`；通用规则见 `DESIGN.md`。本文件里的 P0 / P1 / P2 是**页面内功能优先级**，不是交付批次；交付批次见 `DESIGN.md` 附录 B。

**一句话检验**：每个页面都要回答「这帮助用户进入陌生领域、记住术语吗？」答不上来的内容，不进首屏。

## 0. 页面地图

```
秒记
├─ 折叠态（常驻）
│  └─ 机器人 + 气泡：收术语 / 今日 N / 回顾 N
├─ 顶栏（现在要做）
│  ├─ 收录（默认页）
│  │  ├─ 当前方向：按 当前方向 解释 ⌄（用户自定义）
│  │  ├─ 链接自动识别：文章 / 视频（术语来源）
│  │  ├─ 中文输入：结果里给英文表达
│  │  └─ 结果：术语 / 词条 / 句子 / 剪藏 / 视频
│  ├─ 闪念
│  │  ├─ 新闪念归入（方向）+ 写作区 + 记下
│  │  ├─ 记录流：今天 / 昨天 / 更早
│  │  └─ 详情：原文 + 整理 + 加入复习
│  └─ 回顾
│     ├─ 到期 / 积压 / 清积压
│     ├─ 复习卡（术语 + 领域）
│     └─ AI 考官（按领域出题）
├─ 底栏（回看与工具）
│  ├─ 词库
│  │  ├─ 搜索
│  │  ├─ 默认「术语」；筛选：术语 / 词句 / 剪藏 / 闪念
│  │  ├─ 领域筛选
│  │  └─ 详情（与收录结果共用）
│  ├─ 洞察
│  │  ├─ 7 天 / 30 天 / 本月
│  │  ├─ 领域覆盖 / 学习量 / 薄弱术语
│  │  └─ 周报 / 本地建议
│  └─ 更多（向上弹）
│     ├─ 助手
│     ├─ 设置（5 组）
│     └─ 收起
```

顶栏 3 个 + 底栏 3 个；只有「回顾」带到期角标。点品牌或按 `Esc` 收起，不再放 ✕。

## 1. 全局外壳

窗口固定 **440×680**；顶栏 54px，底栏 48px，中间内容区 560px 可滚动。

```
┌──────────────────────────────────────────────────┐
│ ◉ 秒记  今天 3 · 累计 42        收录  闪念  回顾 5 │ 顶栏
├──────────────────────────────────────────────────┤
│                                                  │
│                    页面内容                      │
│                                                  │
├──────────────────────────────────────────────────┤
│                 词库      洞察      更多           │ 底栏
└──────────────────────────────────────────────────┘
```

- 品牌区：28px 机器人 + 「秒记」+ 一行今天的计数；点击收起。
- 顶栏放「现在要做」的三个动作；底栏放「回看与工具」的三个入口，文字用次级墨色，当前项朱砂短线。
- 底栏「更多」向上弹浮层（助手 / 设置 / 收起），不是第四个页面。
- 内容区左右 16px；页面标题 20px；分区之间 24px。

## 2. 折叠态

```
        ┌──────────────┐
        │   回顾 5     │
        └──────┬───────┘
               ◉
```

- 气泡优先级：剪贴板提示「收 xxx」> 到期「回顾 N」> 今天有记录「今日 N」> 初始「收术语」。
- 单击展开；拖动记住位置；长按只表演，不收起。
- 右键菜单：展开、打开笔记、设置、开机自启、退出。
- 尊重「减弱动态效果」；窗口不可见时暂停空闲动画。

## 3. 收录（默认页）

**用户来这里要做什么**：遇到一个陌生领域的术语，按当前领域弄懂，并收进自己的词库。

| 优先级 | 内容 |
|---|---|
| P0 | 当前方向 + 输入 + 解析 |
| P1 | 剪贴板带入 |
| P2 | 追问、结果里的更多操作（换个方向、重新解析、标记掌握、打开原文、删除） |

收录页不做模式选择：类型由内容自动判断——链接是剪藏/视频，中文概念是术语，单词句子照常；较长的纯中文输入先问一句「这段更像一条闪念」，给「去闪念页记下 / 仍然解析」两个选择，不默默当闪念收录。

### 3.1 空状态

```
┌──────────────────────────────────────────────────┐
│ ◉ 秒记  今天 0 · 累计 0        收录  闪念  回顾   │
├──────────────────────────────────────────────────┤
│ 方向  当前方向 ⌄                                  │
│ 单词、术语、句子，或一个链接…                     │
│                                        [解析]   │
├──────────────────────────────────────────────────┤
│                                                  │
│                       ◉                          │
│        进入一个新领域，从收下第一个术语开始        │
│                                                  │
└──────────────────────────────────────────────────┘
```

- **当前方向**是首屏的一部分，不是设置里的隐藏项。用户可以在收录页直接切换，或**当场新建一个方向**。
- 下拉里只列用户自己定义的方向，不提供固定行业选项：

```
按 当前方向 解释 ⌄
┌──────────────────────────────┐
│ 搜索或新建方向…               │
│ 编程                          │
│ 供应链                        │
│ 医疗器械注册                  │
│ + 新建「跨境电商税务」        │
└──────────────────────────────┘
```

- 没有方向时显示「未设方向 ⌄」，点开就是「新建方向」；方向数量不限、行业不限。
- 输入框是首屏焦点，展开后自动聚焦。
- 占位符对比度 ≥ 4.5:1；不用「请输入」这类废话。

### 3.2 术语结果

```
│ [术语] port                  按 当前方向 解释 ⌄  ⋯ │
│ 网络端口：一台主机上用于区分不同服务的逻辑编号。  │
│                                                  │
│ 领域例句                                          │
│ The service listens on port 8080.                │
│ 这个服务监听 8080 端口。                          │
│                                                  │
│ 为什么重要                                        │
│ 分不清端口和 IP，会在排查连接问题时绕远路。        │
│                                                  │
│ 常见误解  端口不是物理接口；和协议不是一回事。    │
│ 相关概念  IP 地址 · 套接字 · 反向代理            │
├──────────────────────────────────────────────────┤
│ 追问  继续问点什么…                        [发送] │
```

- 类型标签 `[术语]` / `[词条]` 用 11px 弱墨，不做彩色胶囊。
- 术语标题 26px 衬线（英文）/ 26px 无衬线（中文）；长术语降到 20px 并完整换行。
- **中文术语卡**在释义下方给「英文表达」分区：最贴切的英文说法（衬线），备选与辨析在「近义」标签里；替代了独立的「中译英」模式。
- 顶部的「按 当前方向 解释 ⌄」是当前领域，点开可以：
  - 换一个方向重新解释（需要行为支持，见第 11 节）；
  - 查看这个词在另一个领域里的意思（如果已收录）。
- 方向名来自用户自己定义；「编程 / 金融 / 财税」只是示例，不是产品枚举。
- 分区用小标题 + 分隔线，不编号、不加 `//`。
- 「⋯」里：换个方向、重新解析、标记掌握、打开笔记、删除。

### 3.3 文章 / 视频（术语来源）

```
│ [剪藏] 为什么我们总是记不住读过的书               │
│ 少数派 · 12 个术语 · 11-16                  ⋯   │
│                                                  │
│ 摘要                                              │
│ 文章从注意力、编码和检索三个环节解释…             │
│                                                  │
│ 术语 12 个                        [全部收进复习] │
│ 检索练习 · 间隔效应 · 编码特异性 …                │
│                                                  │
│ 原文（展开）                                      │
├──────────────────────────────────────────────────┤
│ 追问  继续问点什么…                        [发送] │
```

- 文章/视频不是「稍后读」，而是**术语来源**：先看摘要和术语，再决定收哪些。
- 视频用同一个壳：类型标签 `[视频]`，元信息换成平台 · 作者 · 时长 · 8 个术语。
- 文章标题 20px 无衬线；超长标题完整换行，不截断。
- 原文默认折叠；展开后只读、可滚动。

### 3.4 加载与错误

```
│ 正在提取正文…                              [取消] │
│ 正在生成摘要…                                     │
```

- 超过 1 秒显示阶段文字；超过 10 秒给「取消」。
- 错误就地显示在结果区，不用 toast 代替：

```
│ 知乎拒绝了这个请求（403），它要求登录态。          │
│ [去设置填写 Cookie]  [重试]                       │
```

- 其他错误：404 / 付费墙 / 内容太短 / 视频没有字幕 / 链接失效 / 无网络 / 没有 API Key。每条都说「发生了什么 + 下一步」。

### 3.5 结果类型表

| 类型 | 标题 | 正文分区 |
|---|---|---|
| 术语 | 术语（衬线/无衬线 26px） | 定义 / 英文表达（中文术语）/ 领域例句 / 为什么重要 / 常见误解 / 相关概念 / 追问 |
| 词条 | 单词（衬线 26px） | 释义 / 例句 / 近义 / 词源 / 追问 |
| 句子 | 句子（20px） | 翻译 / 结构 / 用法 / 追问 |
| 剪藏 | 文章标题（20px 无衬线） | 摘要 / 术语 / 原文 / 追问 |
| 视频 | 视频标题（20px 无衬线） | 摘要 / 术语 / 字幕 / 追问 |

「中译英」不再是独立结果类型：中文输入走术语卡，英文表达在卡内；旧数据里的 lookup 词条仍按原样式显示。

## 4. 闪念

**用户来这里要做什么**：随手记下一个判断、一段摘录或没想清楚的问题，不打断思路。

| 优先级 | 内容 |
|---|---|
| P0 | 写作区 + 记下（先落盘） |
| P1 | 记录流（今天 / 昨天 / 更早）、整理状态 |
| P2 | 加入复习、更多操作（打开笔记、删除）、重新整理 |

### 4.1 正常状态

```
┌──────────────────────────────────────────────────┐
│ ◉ 秒记  今天 7 · 累计 10        收录 [闪念] 回顾  │
├──────────────────────────────────────────────────┤
│ 闪念 [记]                             今天 3 条   │
│ 新闪念归入  编程 ⌄                                │
│ ┌──────────────────────────────────────────────┐ │
│ │ 记下一个判断、一段摘录，                      │ │
│ │ 或还没想清楚的问题…                           │ │
│ │                                              │ │
│ └──────────────────────────────────────────────┘ │
│                           Ctrl+Enter  [记下]     │
│                                                  │
│ 今天                                             │
│ 14:20  不要把复习当重读。先合上，试着讲一遍，     │
│        再翻回去对照。                             │
│        编程  已整理                               │
│ ──────────────────────────────────────────────── │
│ 11:05  牛鞭效应：需求波动沿供应链向上放大，       │
│        越靠近源头越剧烈。                         │
│        供应链  整理中                             │
│                                                  │
│ 昨天                                             │
│ 18:40  《技术的本质》里说，术语的边界就是一个     │
│        领域看世界的方式。                         │
│        编程  整理失败 · 重试                      │
│                                                  │
│                              查看全部闪念         │
├──────────────────────────────────────────────────┤
│                 词库      洞察      更多           │
└──────────────────────────────────────────────────┘
```

- 「新闪念归入」只决定新闪念的方向；列表始终显示所有方向的最近闪念，不被过滤。
- 「记下」先原样落盘（断网、没 Key 都能记），AI 整理随后补上：整理中 → 已整理 / 整理失败 · 重试；没整理的标「未整理」，内容照常可读、可搜。
- 记下后输入框原地清空并保持焦点，可连续记录；只提示「已记下」，不跳页。
- 时间用等宽数字；行与行用细线分隔，不套卡片。
- 「查看全部闪念」跳到词库并筛到闪念；本页负责写和最近看，词库负责完整归档与搜索。

### 4.2 展开一条闪念

```
│ 14:20  不要把复习当重读。先合上，试着讲一遍，     │
│        再翻回去对照。                             │
│        编程  已整理                               │
│   ┌────────────────────────────────────────────┐ │
│   │ 不要重读。先合上，试着讲一遍，再翻回去对照。│ │
│   │ ────────────────────────────────────────── │ │
│   │ 整理                                       │ │
│   │ · 先自己说出来，再看答案                    │ │
│   │ · 重读会制造「已经会了」的错觉              │ │
│   │ 术语  检索练习                              │ │
│   │ 加入复习   更多操作   重新整理              │ │
│   └────────────────────────────────────────────┘ │
```

- 原文在前，AI 整理收在细线之后，默认展开时只看到原文——AI 不改写原文，版式上体现。
- 「加入复习」把这条闪念排进复习队列（默认不进）；已在队列显示「已在复习队列」。
- 「更多操作」打开词条操作浮层（打开笔记、标记掌握、删除）。

### 4.3 空状态

```
│ 还没有闪念。想到什么就写下来，                    │
│ AI 随后整理，不打断记录。                         │
```

## 5. 回顾

**用户来这里要做什么**：在忘记之前回顾术语，确认自己第二次遇到时能认出来。

| 优先级 | 内容 |
|---|---|
| P0 | 开始回顾 / 翻面 / 自评 |
| P1 | 清积压、AI 考官 |
| P2 | 统计明细、下一个到期时间 |

### 5.1 有到期

```
┌──────────────────────────────────────────────────┐
│ ◉ 秒记  今天 3 · 累计 42        收录  闪念  回顾 5 │
├──────────────────────────────────────────────────┤
│ 回顾                            今天 5 个术语到期 │
│ 已收 32 · 复习过 21 · 稳固 9                      │
├──────────────────────────────────────────────────┤
│                                                  │
│                今天 5 个术语到期                  │
│                先回忆，再翻面。                   │
│                  [开始回顾]                       │
│                清积压 · 全部 8 个                 │
│                换种方式：AI 考官                  │
│                                                  │
└──────────────────────────────────────────────────┘
```

- 首屏只有一个主按钮；积压和考官都是次级文字按钮。
- 「已收 / 今天 / 累计 / 领域覆盖」只统计术语类词条（术语 / 词条 / 句子 / 中译英）；闪念、剪藏不计入术语积累。「复习过 / 稳固」只跟复习状态有关。

### 5.2 没有到期

```
│                今天没有到期的术语                 │
│                下一个到期：明天                   │
│                [去收一个术语]                     │
│                [打开词库]                         │
```

### 5.3 复习卡

正面：

```
│ 回顾 · 1/5                                       │
│ [术语] port                        编程          │
│                                                  │
│ 先回忆，再翻面。                                  │
│                                                  │
│ [显示答案]                                       │
```

背面：

```
│ 回顾 · 1/5                                       │
│ [术语] port                        编程          │
│                                                  │
│ 网络端口：一台主机上用于区分不同服务的逻辑编号。  │
│                                                  │
│ [1 没想起]  [2 模糊]  [3 想起来了]               │
```

- 类型标签按条目 kind 显示：术语 / 词条 / 句子 / 中译英 / 剪藏 / 视频 / 闪念。
- **领域标签必须显示**：同一个术语在不同领域可能是不同的卡。领域名是用户自己定义的方向名；「编程」只是示例。
- 正面：术语显示术语；词条显示单词；句子显示句子；剪藏/视频显示标题；闪念显示标题或首句。
- 背面：术语/词条给定义/释义；句子给翻译；中译英给英文表达；剪藏/视频给摘要；闪念给整理要点。
- 快捷键提示只出现一次，不常驻。

### 5.4 本次回顾结束

```
│ 这次回顾了 5 个术语                               │
│ 想起 3 · 模糊 1 · 没想起 1                        │
│ 下一个到期：明天                                  │
│ [再清 3 个积压]   [回到收录]                      │
```

### 5.5 AI 考官

```
│ AI 考官 · 1/5                    领域：编程       │
│ 在编程语境里，「port」指的是什么？                │
│ A …                                               │
│ B …                                               │
│ C …                                               │
│ D …                                               │
```

- 按领域出题，干扰项同领域，避免「明显荒谬」的选项。
- 领域名来自用户自己定义的方向；示例里的「编程」可以换成任何方向。
- 答完立即判分 + 一句解析；答对进入下一阶段，答错明天回来。

## 10. 定位检验

后续每个页面、每个功能都拿这四句检验：

1. 它是否帮助用户**进入陌生领域**？
2. 它是否让术语**按领域**被解释和记住？
3. 它是否减少**第二次遇到还要再查**的次数？
4. 它是否在制造新的断点，而不是减少断点？

## 11. 已确认

1. 一级导航：顶栏 **收录 · 闪念 · 回顾** + 底栏 **词库 · 洞察 · 更多**（2026-11-17 确认）；同一栏不超过 3 个；更多菜单向上弹。
2. 收录页显示**当前方向**（按 当前方向 解释 ⌄），并允许在解析前切换或当场新建；**方向由用户自己定义，数量不限、行业不限，本文中的「编程 / 金融 / 财税」只是示例，不得写死为枚举**。收录页不做模式选择，类型由内容自动判断。
3. 词库默认「术语」，类型筛选 术语 / 词句 / 剪藏 / 闪念，另有领域筛选。
4. 回顾按领域展示术语；AI 考官按领域出题。
5. 同一个术语在不同领域怎么存：**已选乙（2026-11-17）**：一个术语 × 一个方向一条记录，回顾时分别出现。
   - 术语、词句、中译英按「术语 + 方向」各存一条；第一个方向沿用原主键，其余方向用「原主键@方向 id」，老数据不迁移。
   - 解析前可以明确选方向；选了就强制按该方向解释，不再让 AI 猜。
   - 换方向时主键一起换，Obsidian 标记块同步改名；目标方向已有同一条术语时拒绝并提示，不静默合并。
   - 剪藏按网址、闪念按标题仍各存一条；同一剪藏换方向会更新这条剪藏的方向。
6. `生词本.md` 本期不改名，只在 UI 上叫「笔记文件」。
7. **闪念独立成页（2026-11-17 确认）**：顶栏入口；先原样落盘、AI 随后整理、失败可重试；**默认不进复习队列**，详情里「加入复习」才排期；AI 只整理不改写，原文在前。**每条闪念独立成键（`note:` 前缀，2026-11-18 确认）**，首行相同的两条不再互相覆盖；旧闪念沿用原键，不受影响。
8. **中译英并入解析结果（2026-11-17 确认）**：中文输入的术语卡给「英文表达」分区；独立的「中译英」模式入口取消，旧 lookup 数据仍能正常显示与复习。
9. **统计口径（2026-11-18 确认）**：收录量（今天 / 累计 / 已收）与领域覆盖只统计术语类词条；闪念、剪藏是记录与来源，不算术语积累；复习次数与连续天数仍覆盖整个复习队列。

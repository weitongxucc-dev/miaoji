# 秒记参考分析

状态：初稿（2026-11-17），基于 UI 审计期的实际使用与截图观察；**当前版本、具体页面与链接尚待逐条联网核实**。按 `DESIGN.md` 第 1 章，核实完成前不得进入页面设计。

参考优先级：William 的截图 > 官方设计规范 > 已上线产品的实际使用 > 其他。以下只记录「借鉴手法」和「明确不借鉴」，不抄外观。

> 产品中心：跨领域术语的「按方向解释 + 定期回顾」。以下参考按这个中心筛选借鉴点；「词条 / 释义」是通用说法，实际界面用「术语 / 词条」。

## 1. Readwise Reader（同品类：阅读与标注）

- 观察页面：阅读视图、标注列表、侧边信息栏。
- 它解决的问题：长文阅读时保持正文优先，同时让标注和元信息随时可取。
- 借鉴：
  - 英文标题 / 正文用衬线，中文与界面文字用无衬线，阅读感和操作感分开；
  - 元信息压暗、字号小，不抢正文；
  - 用间距和分隔线组织内容，不用卡片套卡片。
- 不借鉴：
  - 多栏阅读布局（秒记只有 440px 宽）；
  - 复杂的标注筛选与侧栏（秒记的剪藏只需「原文 / 术语 / 追问」）。
- 对秒记的落点：英文词头与例句用衬线；释义和界面用无衬线；元信息用 11px 弱墨。

## 2. Anki（同品类：间隔复习）

- 观察页面：今日到期、复习卡、牌组统计。
- 它解决的问题：让用户相信「今天该复习什么」是系统算出来的，而不是随便推的。
- 借鉴：
  - 复习页先给「今天多少到期、还剩多少」，再开始；
  - 自评按钮少而明确，结果立即反映到下一次到期；
  - 统计只展示能指导行动的数字，不做装饰性图表。
- 不借鉴：
  - 牌组 / 模板 / 插件式复杂度；
  - 老式的表格与设置密度；
  - 用「连续打卡」制造压力。
- 对秒记的落点：回顾页保留「已收 / 复习过 / 稳固」的诚实数字；积压和毕业确认用一句话说清，不做游戏化。

## 3. Obsidian（同生态：本地笔记）

- 观察页面：库选择、文件写入、设置中的路径与同步。
- 它解决的问题：让用户相信数据是自己的、可被其他工具读取。
- 借鉴：
  - 明确显示「写到哪个文件」，路径可见、可打开；
  - 本地优先的措辞只出现一次，不反复解释；
  - 设置项按「输入 / 输出 / 系统」分组。
- 不借鉴：
  - 图谱、插件市场、双链等复杂度；
  - 深色主题作为默认。
- 对秒记的落点：笔记组只保留「检测状态 + 库 + 文件 + 写入开关 + 重建」；「数据只存本机」在页脚说一次。

## 4. Raycast（跨品类：桌面工具面板）

- 观察页面：单一输入框、结果列表、键盘操作、扩展入口。
- 它解决的问题：用一个小面板在任意软件上方完成高频动作，不打断当前工作。
- 借鉴：
  - 一个输入框承担主任务，结果在下方就地展开；
  - 键盘优先，常用动作有快捷键；
  - 结果行信息密度高，但层级靠字重和间距，不靠边框；
  - 低频能力收进「更多」，不占主栏。
- 不借鉴：
  - 启动器式的命令面板外观、玻璃材质；
  - 大量扩展和图标墙。
- 对秒记的落点：查词页的主输入 + 结果卡；导航用 4 个文字入口 + 更多；功能图标不承担导航。

## 5. Linear（跨品类：高密度桌面应用）

- 观察页面：列表、详情、设置；官方文章《A calmer interface》。
- 它解决的问题：在高信息密度下保持安静，让用户先看到内容，再看到控件。
- 借鉴：
  - 次要元素压暗，结构靠间距和对齐，不靠边框；
  - 只保留一个强调色，用于当前项和主操作；
  - 设置项一行一项，说明按需展开；
  - 状态用图形 + 位置表达，不只靠颜色。
- 不借鉴：
  - 深色底 + 单一荧光色的组合；
  - 命令面板和快捷键驱动的重度工作流（秒记用户不必先学命令）。
- 对秒记的落点：设置页去掉卡片边框与常驻说明；朱砂只做语义强调；列表用间距分组。

## 平台规范

- Windows：以当前版本 Fluent 为准，核实工具栏、焦点、对比度、点击目标等要求。秒记是固定 440×680 的无边框面板，不使用 Windows 大标题栏。
- Apple HIG 只借鉴一条：工具栏只放最重要的动作，其余收进 More 菜单。秒记不运行在 macOS，不套用 iOS 导航。
- 不把任何平台的「当前风格」写死进代码；平台规范会变。

## 与秒记设计决策的关系

- 参考分析支持 `DESIGN.md` 的「安静纸面」：纸色 + 朱砂 + 像素机器人保留，但中文正文改用无衬线、卡片去边框、终端装饰清理。
- 产品中心是「跨领域术语」：Readwise 的阅读密度服务术语来源，Anki 的复习诚实服务术语留存，Obsidian 的本地优先服务个人术语库，Raycast 的单输入服务「遇到就收」，Linear 的克制服务高密度术语阅读。
- 导航的「4 个文字入口（收录 · 回顾 · 词库 · 洞察）+ 更多」来自 Raycast 的「低频收进更多」与 HIG 的「工具栏只放重要动作」。
- 设置页的「一行一项、说明按需展开」来自 Linear；统计页的「只留有行动意义的数字」来自 Anki。
- 明确不采用：Readwise 的多栏、Anki 的牌组复杂度、Obsidian 的插件复杂度、Raycast 的玻璃材质、Linear 的深色荧光组合。

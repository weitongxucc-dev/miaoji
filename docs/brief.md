# 秒记项目档案

本文件只放秒记专属的产品事实与边界。通用界面规则见 `DESIGN.md`，页面结构与线框见 `docs/wireframes.md`。

## 谁用

需要不断进入陌生领域、做到一专多能的知识工作者：产品、运营、管理、财务、技术、咨询、创业等角色。他们不是要成为每个领域的专家，而是要在跨领域协作中听懂、说清楚、做判断。当前以 William 本人为主。

## 场景与任务

在进入一个新领域时，会遇到大量新词汇和专业术语（例如编程、金融、财税、管理、供应链、AI……这些只是举例，实际方向由用户自己定义，产品不预设行业）。第一次听到解释能懂，第二次遇到又想不起来，只能重新查。秒记让你在遇到的那一刻收下，按当前领域解释，定期回顾，直到第二次遇到不用再查。

一句话：**遇到术语 → 按领域弄懂 → 收进词库 → 回顾到不忘。**

## 核心任务 Top 3

按重要性排序，用来决定每个页面的 P0：

1. **遇到陌生术语时，按当前领域弄懂并收下。**
2. **在忘记之前回顾，直到第二次遇到不用再查。**
3. **看见自己在哪些领域积累了术语、哪些还不稳。**

## 必须有的功能

- **学习方向**：用户自己定义当前进入的领域，数量不限、行业不限；同一个词在不同方向按不同含义解释，各存一条、分别复习。
- **术语卡**：定义、领域例句、为什么重要、常见误解、相关概念。
- **词句解析**：单词、短语、句子；中文术语也可以，解析结果里给出英文表达。
- **文章/视频术语提取**：从网页、公众号、视频里批量发现术语，一键收进复习。
- **闪念**：独立页面随手记领域里的概念、判断、摘录；先原样保存，AI 只整理不改写；默认不进复习，需要时手动加入。
- **追问**：对当前术语继续提问，回答写进 Obsidian。
- **词库**：默认术语；按领域和类型筛选；搜索、热词、已掌握。
- **回顾**：到期、积压、清完、毕业确认、AI 考官；卡片显示领域。
- **洞察**：领域覆盖、学习量、薄弱术语、周报、本地建议。
- **Obsidian**：个人领域术语库，写入本地文件。
- **助手**：跨领域批量操作（搜索、收录、改方向、看回顾、收术语、生成周报）。
- **设置**：AI 服务、输入与抓取、学习、笔记与报告、应用与系统。

## 明确不做的功能

防止擅自加戏：

- 不做社交、分享、云同步、账号体系。
- 不做行为画像、广告、推荐流。
- 不做云端转换 / 代理服务（如 r.jina.ai）。
- 不做全文 OCR、PDF 批注、播客、RSS 阅读器。
- 不新增页面、设置组、通知类型，除非 William 确认。
- 不改 API Key、不删笔记或词条；这些是硬约束。数据格式不擅自改；经 William 确认的数据模型调整按确认执行（2026-11-17 已确认「一个术语 × 一个方向一条记录」）。

## 运行平台

Windows 桌面（Electron，无边框固定面板 **440×680**，始终置顶，单实例）。不支持 macOS / Web / 移动端。

## 一句话产品定位

**给需要不断进入陌生领域的人，一个会复习的领域术语本。**

## 调性关键词

**纸面、克制、手作。**

- 纸面：暖纸底、墨色字、像一本摊开的术语本，不像后台系统。
- 克制：一屏一个重点，靠间距和对齐分组，不靠卡片和说明填满。
- 手作：像素机器人、朱砂印章是识别点；不做通用的 AI 渐变和玻璃质感。
